Why SentinelAI needs a staged design

Medical-device reports are noisy, terminology-bound, sensitive, and require auditable human review.
Noisy free text
Reports mix device issues, patient outcomes, timelines, and vague wording.
Broad candidate search
Controlled terminology
The output must be a valid MedDRA term, not a free-form summary.
Search within vocabulary
Exact words and paraphrases
Some reports contain the exact medical term; others describe the same event indirectly.
Lexical + semantic search
Ambiguous meaning
Several terms can be plausible; the system must show uncertainty.
Top-K + confidence
Local and auditable
Open-ended inference on every report would be slow, hard to control, and difficult to audit.
Constrained LLM step
Human accountability
The system proposes candidates; the reviewer confirms, corrects, or rejects.
Human-in-the-loop
Therefore, SentinelAI uses a staged funnel: broad search → careful comparison → constrained suggestion → human review
Not one big model deciding directly — a controlled pipeline that narrows the search space.
